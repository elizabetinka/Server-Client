# Многопоточный HTTP-сервер для управления клиентами и товарами

Это приложение на C++, реализующее многопоточный in-memory HTTP-сервер для управления клиентами и товарами

## Основной функционал

* CRUD для управления клиентами и товарами
* Возможность запустить консольное взаимодействие
* Сервер конфигурируется числом потоков
* Обработка ошибок и валидация входных данных;
* Модульные и интеграционные тесты.

## Используемые технологии

* **C++23**
* **Boost.Asio** — асинхронная работа с сетью
* **Boost.Beast** — реализация HTTP-сервера
* **nlohmann/json** — работа с JSON
* **CMake** — система сборки
* **GoogleTest** — модульное тестирование

## Архитектура

Проект построен по многослойной архитектуре и разделен на независимые компоненты:

* **HttpServer** — обработка HTTP-запросов и маршрутизация
* **Service** — бизнес-логика приложения
* **Repository** — взаимодействие с данными
* **Model** — модели передачи данных между слоями
* **ViewConsole** — взаимодействие с сервером через консоль

## REST API

Сервер предоставляет REST API для управления клиентами и товарами.

### Clients

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/client` | Получить список клиентов |
| POST | `/api/client` | Зарегистрировать нового клиента |
| PUT | `/api/client` | Изменить данные существующего клиента |
| DELETE | `/api/client` | Удалить клиента |

### Items

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/item` | Получить список товаров |
| POST | `/api/item` | Добавить новый товар |
| PUT | `/api/item` | Изменить информацию о товаре |
| DELETE | `/api/item` | Удалить товар или уменьшить его количество |

Документация API представлена в формате **OpenAPI** (`openapi.yaml`) и может быть открыта через Swagger UI.
